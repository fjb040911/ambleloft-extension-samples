先选一个体验 / Start here

无需企业账号。项目、通知和安全存储可直接在此体验；聊天表单和卡片由宿主 Agent 展示。

  1. 项目与聊天：选择本地项目、创建草稿，再继续同一个聊天。
  2. 本地通知：发布后到消息中心查看，重复发布同一事件观察去重。
  3. 聊天里输入：用扩展能力体验馆展示团队计划信息收集表单
  4. 聊天里输入：用扩展能力体验馆的任务卡片登记去上海的差旅，金额 1200 元
  5. 配置本机报销服务后输入：用扩展能力体验馆报销差旅费

完整介绍与服务启动步骤：设置 → 扩展 → 扩展能力体验馆 → 详情（README.md）。

English guide

Link a local project and create a conversation below. Try local notifications without an account. Ask the Agent to present this extension's team-intake form or call cardRender for an interactive card. The travel form needs the optional local expense service. Read the installed README in extension details.

消息动作与企业连接 / Actions & enterprise

先运行 npm run actions:service，并在设置填写 actionServiceUrl。认证单独配置，详见 README；本地消息动作无需账号。

发布后在宿主消息中心点击“提交任务”，并确认写操作。未知结果不会自动重放。

企业认证 / Enterprise authentication

默认 api.example.com 是待管理员替换的声明，不是可用业务服务。只有明确连接操作会打开宿主选择器和系统浏览器。
